General Changes for .NET SDK
____________________________

Code APIs, Dependency libraries, Security settings and Configuration has been migrated from WSE (Web Services Enhancements) 
to WCF (Windows Communications Foundation) framework as per the new requirement.


Changes for both Java and .NET SDK
__________________________________
Class and methods have been renamed due to the XML renaming in MeF Release 9.5 WSDLs & schemas, and in efileTypes.xsd.

Generated service proxy classes and corresponding toolkit ServiceClient classes have been refreshed with latest MeF Release 9.5 WSDL
specification.
