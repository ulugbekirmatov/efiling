Do we need to e-file California payroll taxes?

Pyramos now files the federal payroll returns (941, 941-X, 940) as a Reporting Agent. California has its own quarterly payroll filing with the Employment Development Department (EDD). This brief checks what California requires against EDD's own documents, and what Pyramos would need to file there for clients.

The short version

If Pyramos keeps to federal returns, the only California work left is switching the ACA connection to production. If Pyramos also files California payroll for clients, it needs one EDD enrollment, a signed form from each client, and one of two filing paths, and the fast one needs no certification.

The decision

Every quarter, each California employer must file a return with the EDD. The question is who files it for our clients: the current payroll channel or Pyramos.

03

Two things the first answer got wrong

The first answer was written from memory. EDD's documents corrected two points.

Pyramos does not send EDD a power of attorney for each client

First answerFile a DE 48 power of attorney with EDD for each client.
EDD form DE 231PRAEnroll once as a payroll reporting agent (DE 973B plus the DE 972 agreement, renewed every two years). Keep each client's DE 48 on file and produce it within 24 hours if EDD asks. Send EDD a monthly list of clients added and dropped.
One enrollment plus a monthly list, not one filing per client. It's California's version of Form 8655.

FSET is built like our IRS sender, not just "similar"

First answerFSET is an XML format "aligned with" the IRS one.
EDD guide DE 545FSET is a SOAP web service with MTOM attachments, built to the shared IRS and state standard, with IRS MeF namespaces in its messages. Each send is one zip that can hold many employers' returns. Login is a username and password, not a device certificate.
Much of the shape of our IRS sending code would carry over.
04

If we file California: two paths

Both paths satisfy the e-file mandate. They differ in setup cost and in how much is automated.

Fast · no certification

e-Services bulk upload

Covers
The DE 9C wage file as XML, ICESA or MMREF, up to 10 MB zipped.
Setup
An e-Services for Business account only. There is no test environment; the upload itself is the test.
Cost
A person uploads each file by hand. The DE 9 and the DE 88 payment go through e-Services or EFT separately.
Fits
A few clients, or the first quarters while FSET is being built.
Automated · ATS-style project

FSET, application to application

Covers
DE 9, DE 9C, DE 88 (an ACH debit), DE 34 and DE 542. Up to 32,000 records per send.
Setup
An e-Services account, then the DE 547 enrollment, then certification on EDD's Client Test environment: run the test cases, then send one transmission shaped like real production.
Limits
Amended DE 9 or DE 9C returns can't go through FSET. Corrections go through e-Services or the DE 9ADJ form.
Fits
Many clients filed from the same app that sends the 94x.
