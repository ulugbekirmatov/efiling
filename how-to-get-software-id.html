01

The problem

Pyramos already has a login. Login is not enough to file.

The return XML has a required header field named SoftwareId. The schema wants exactly eight digits. The live composer reads that value from MEF_SOFTWARE_ID. The env var is still empty because IRS has not issued the number.

ETIN 44754 is the Software Developer test account. It authenticates the SOAP session. It does not fill <SoftwareId>.

03

The analogy

Getting a Software ID is like registering a car and receiving the license-plate number. You fill out the form at the counter. The clerk prints the plate on the spot. You still need an inspection sticker before the highway. Where this breaks: a plate usually lasts with the car. A Software ID is per tax year and per tax package. Tax year 2027 needs a new Save.
04

The rule

You must be an authorized user on a Completed e-file application, with Principal rights or the Add & Change Software Package Information permission. Then you add a package and Save. The system issues the Software Identification Number for that package. Publication 5078 §2.4 is the official wording.

05

Click Save in e-Services

This is the only issuance path. There is no paper form and no mailed letter for the ID itself.

1
Confirm the Software Developer option already true for Pyramos

The e-file application must include Software Developer. That option is what opens the Software Packages tab. CLAUDE.md already lists ETIN 44754 as Software Developer, Test. If the tab is missing, call e-Help before you hunt for a questionnaire that cannot exist yet.

2
Permission Principal, or delegated

Grant Add & Change Software Package Information to whoever will click Save. QuickAlerts and Pub 5078 both name that permission. Responsible Officials who lack it will see the tab and still cannot add a package.

3
e-Services UI the Save that mints the ID

The screens at Get the Software ID walk this click path. Sign into the completed IRS e-file application. Choose Organization Role. Open the application with View/Edit. Select the Software Packages tab. Click Add Software Package toward the bottom. Fill the pop-up for the 94x quarterly package you will test. Click Save. The ID appears automatically on that package row.

4
Scope the package one ID per tax year and tax package

Pub 5078. Software Developers need a new Software ID for each tax year and each tax package they support. For this repo that means a 94x quarterly package for tax year 2026. Project guides expect a number that looks like 2699NNNN. Treat that pattern as a hint, not a value you type yourself. IRS assigns the eight digits.

5
Call e-Help 866-255-0654

Tell them you are ready to test. There is no self-service ATS scheduler. Saving the questionnaire is not the same as being scored.

↳
The QuickAlerts October 2025 note adds the View/Edit click that Pub 5078 skips. Use the longer path. If Save does nothing, you are probably on the summary page instead of inside the application.
06

Then wire it into the app

The ID lives in one env var. The return header is the only place it goes.

# mef-spring-boot-integration/.env
MEF_SOFTWARE_ID=<the 8 digits from the Software Packages row>

application.yml binds that to mef.reporting-agent.software-id. ReportingAgentReturnXml writes <SoftwareId> in the 94x header. It does not belong in login, ASID, or the NewSend manifest.

Do not paste these

12345678 is the ATS scenario sample in Return941-Scenario1.xml. 00000000 is the offline schema stand-in. 11111111 is a unit-test fake. None of them have passed testing for Pyramos.

09

Traps

Easy to get wrong

  • Issuance and ATS Pass are different clocks. Rule R0000-904-03 rejects a brand-new ID until IRS records that it passed testing for the form family and tax year.
  • A Reporting Agent who buys vendor software can skip Software Developer and reuse the vendor ID. Pyramos writes the transmitter, so it cannot skip.
  • EFIN 102192 starts with 10. Rule R0000-118-01 still forces OnlineFiler on that prefix. Getting a Software ID does not fix that. e-Help still owns that ticket.
  • Pub 5830 ClientSoftwareTxt is a Toolkit SOAP header. It is not the return-header Software ID.
  • mef-efiling-onboarding.html never documents this step. Use Pub 5078 §2.4 and pyramos-mef-registration.html phase 2b.
10

FAQ

Do ATS and Production get different Software IDs?
No local IRS source says that. Pub 5078 talks about one ID per tax year and tax package. ATS versus Production is an ETIN transmission-status split (44754 stays Test, 44753 flips after the communications test).
What if the Software Packages tab is empty or missing?
Empty means add a package. Missing usually means the Software Developer option is not on the application, or you are not inside View/Edit. ETIN 44754 is evidence the option exists. Call 866-255-0654 if the tab still is not there.
Do I need a new ID for Form 941-X or 94x annual?
Pub 5078 says each tax package. Project guides treat 94x annual as YY88NNNN and PIN registration as its own package. For the first ATS send, complete the 94x quarterly 2026 package. Ask e-Help before you invent extra packages.
Where is the official questionnaire field list?
Not in this repo and not in the Pub 5078 extract. The screen is the Add Software Package Information pop-up. Fill every required field IRS shows, then Save.
