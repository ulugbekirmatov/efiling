Get the Software ID

If you can sign into e-Services, follow the eight screens. Add one 94x quarterly package for tax year 2026. Click Save. Send the eight digits back. IRS layout will not match these sketches. The button names match QuickAlerts, 1 Oct 2025.

Before you start
  • You can sign into IRS e-Services for Pyramos Software LLC.
  • You are a Principal, or you have the Add & Change Software Package Information permission.
  • The e-file application status is Completed.
1

Open the completed e-file application.Go to E-file provider services. Click Access e-file application. If IRS asks you to sign in, sign in.

6

Fill the pop-up for the 94x quarterly package you will test.IRS does not publish the field list. Fill every required field the pop-up shows. If it asks for a tax year, enter 2026. If it asks for a form family or package type, do not choose 94x annual. Do not choose PIN registration. Choose 94x quarterly. If it asks for a product name, enter Pyramos MeF 94x.
