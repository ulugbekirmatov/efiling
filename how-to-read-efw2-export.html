How to read w2_export-efw2.txt

This file sends Copy A of 244 W-2s to the Social Security Administration. Every line is one record, and every value sits at a fixed character position. Below, line 3 of your own file is decoded field by field. Then you can decode any other line yourself.

~/Downloads/w2_export-efw2.txt · 250 lines · 512 characters each · CR LF line ends
The two-sentence version

Each line is one 512-character record, and its first two letters name it: RA submitter, RE employer, RW one employee's W-2, RT that employer's totals, RF end of file.

A value is found only by its position, and money is whole cents with no decimal point: characters 188–198 of line 3 read 00002036696, which is Box 1 wages of $20,366.96.

02Start with the first two characters

Characters 1–2 tell you which layout the rest of the line follows. Your file has five record types, always in the order below. Each employer gets its own block: one RE, its RW lines, then one RT.

Four other types are absent. RO and RU carry rarer Box 12 codes and Puerto Rico amounts. RS and RV carry state wages and state tax. With no RS lines, this file holds federal data only.

Reading an RW line is like reading a paper W-2 where you know each box only by where it sits on the page. Where this breaks: the paper form prints labels and decimal points, and this file prints neither. You read 00002036696 as $20,366.96 only because you know slot 188–198 holds cents. A blank and a zero also differ: name and address slots pad with spaces, money slots pad with zeros.

04The rules for any field

These six rules decode every line in the file. Line 3 above follows each one.

  1. One line is one record of exactly 512 characters, ending in a Windows line break (CR LF). The line break is not part of the 512.
  2. Characters 1–2 pick the layout. RW means the employee layout, RT the totals layout, and so on.
  3. Positions count from 1. "188–198" means the 188th through the 198th character, 11 characters in all.
  4. Money is in cents, right-aligned, zero-filled, with no decimal point or sign. Divide by 100. RW slots are 11 digits wide; RT total slots are 15 digits wide (characters 10–24 of line 249 read 000000680185698, which is $6,801,856.98).
  5. Text is uppercase, left-aligned, and space-filled to the slot's width. A slot of all spaces means "not reported".
  6. A one-character flag is 0 for no and 1 for yes. Coded slots use letters instead: Employment Code R (line 2, position 219) means regular Form 941 employment.

The same reads work in a terminal. Use cut -c with the positions from the layout:

# count each record type
cut -c1-2 ~/Downloads/w2_export-efw2.txt | sort | uniq -c

# Box 1 (positions 188-198) of every employee, in dollars, with its line number
awk 'substr($0,1,2)=="RW" { printf "%d  %.2f\n", NR, substr($0,188,11)/100 }' ~/Downloads/w2_export-efw2.txt

# one slot of one line: line 156, Box 3 (positions 210-220)
sed -n 156p ~/Downloads/w2_export-efw2.txt | cut -c210-220

# every SSA rule at once: the repo's checker, with the 2025 wage base
git show feature/w2-accuwage-files:mef-spring-boot-integration/efw2_check.py > ~/efw2_check.py
python3 ~/efw2_check.py --tax-year 2025 ~/Downloads/w2_export-efw2.txt

In VS Code or Cursor, the status bar shows "Col N" for the cursor. Col 188 is the first character of Box 1.

07Fix before you upload

The repo's checker (efw2_check.py, run with --tax-year 2025) found one error and one warning, both on line 156. Reading line 1 by hand shows test values in the submitter record. Order: SSA reject, SSA warning, wrong data, then a note.

Error · AccuWage rejects this
Line 156: Box 3 is over the 2025 Social Security wage base

Social Security tax stops once an employee earns the wage base, so Box 3 can never exceed it. This employee's Box 4 tax already stops at the base. Only the wage slot was not capped.

Note · not an error
State wages and state tax are not in this file

The file has no RS records, so no Box 15–17 data. SSA does not need them. The state copies for PA (230 employees), NJ (6), and the other eight states go to each state separately.
