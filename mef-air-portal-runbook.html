Part C · SSA: request SSNVS access

A W-2 whose name and SSN do not match SSA's records lands in SSA's suspense file, and the employee's earnings never post. SSNVS (Social Security Number Verification Service) checks every name and SSN pair before the wage file goes in. It runs in SSA's Business Services Online (BSO), not in IRS e-Services, so it needs its own sign-in and its own access request. The bulk tool is already built (ssnvs-name-ssn-check.html). Only the access is missing.

Mail delay
SSA mails an activation code to Pyramos at the address the IRS has from its Form 941 or SS-4. It usually arrives within two weeks. A request older than 60 days is void and has to be made again.
Request in December
Code arrives late December. SSNVS for ten clients, fixes, and W-2 rebuilds all squeeze into January, against the February 1, 2027 W-2 deadline.
Request today, 2026-11-03
Code arrives around November 17. It is active before BSO opens for TY2026 on December 8.
Result
The two-week letter is off the critical path. SSNVS can run on every client's employee list the week BSO opens.
C1

Check where the letter will go

C1
Confirm that the IRS address for Pyramos's EIN is the address where mail reaches you today.

SSA does not mail the activation code to the address you type in BSO. It mails it to the address the IRS has on file for Pyramos's EIN, from its Form 941 or Form SS-4. The letter is addressed to the employer and tells them to hand you the code. If Pyramos has moved, file Form 8822-B with the IRS first. A code sent to an old address is lost, and you start over.
