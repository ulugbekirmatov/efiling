How to e-file W-2 forms for Pyramos clients

Tax year 2026 Forms W-2 are due 2027-02-01. This page answers where they go, what file SSA takes, what each of the eleven payroll jurisdictions wants on top, what a Reporting Agent must have in place, and what to build in the Spring Boot repo.

Two-sentence version

W-2s go to the Social Security Administration, not the IRS, so neither the IRS MeF channel this repo already speaks nor IRS IRIS can carry them. The pipeline for January 2027 is: Java builds and validates one EFW2 fixed-width file covering every client, a person runs it through AccuWage Online and uploads it in BSO, and the app stores the Wage File Identifier and polls status.

State W-2 reporting is a separate obligation with its own file, portal and reconciliation form in ten jurisdictions. Four of them will reject an unmodified copy of the SSA file, and New York wants something else entirely.

01 · Where W-2s go, and why the existing code cannot carry them

The MeF integration in this repo sends Form 941 returns to the IRS over SOAP. A W-2 is not a return. It is a wage statement whose Copy A goes to SSA, which forwards the federal fields to the IRS and forwards nothing to any state. The three federal systems are easy to confuse because all three take employer data in January.

02 · The federal pipeline, and where the human sits

SSA documents exactly three intake channels for EFW2 files and a fourth that is shut. Electronic Data Transfer is for federal and state agencies only. The Electronic Wage Reporting Web Service (EWRWS) is a SOAP service built for consolidators such as payroll providers, and it can submit files and poll status. Its page carries an alert: "SSA is currently not accepting new EWR Web Service users/consolidators." That leaves the browser.

Java does thisA person does this in BSO
1
Register once, as a person, with Pyramos's EIN human

One employee registers in BSO through Login.gov or ID.me, checks the Third-Party box, and uses Pyramos's own EIN and address. "You may not register on behalf of another person." SSA mails one activation code per service to Pyramos's IRS address of record, usually within two weeks. Request Wage Reporting and SSNVS. Clients do not need BSO accounts today. The 8-character BSO User ID this produces goes into the file as the electronic signature. Register two people, because the User ID leaves with the employee.

2
Generate one combined EFW2 file for all clients java

One RA record for Pyramos, then for each client one RE, its RW records, optional RO and RS records, one RT (plus RU if any RO), and one RF at the end with the total RW count. SSA asks for this: "We encourage you to file combined reports to avoid creating a separate file for each employer."

3
Validate locally, then in AccuWage Online java human

The local validator catches what would otherwise cost an upload cycle. AccuWage Online is the SSA checker inside BSO. It is not formally mandatory, but BSO no longer accepts malformed files and SSA tells filers to retest after every fix. AccuWage does not check names against SSNs. That is SSNVS.

4
Upload through Wage File Upload human

Every upload is a live filing. There is no test indicator in the file and no test environment. Front-end validation returns within 60 seconds with a receipt and a Wage File Identifier (WFID). Save that page. If you spot a mistake while status is RECEIVED you can delete the submission yourself. While IN PROCESSING you must phone SSA. After COMPLETE the only remedy is a W-2c.

5
Record the WFID and poll status java human

SSA does not notify on success. A person checks Submission Status in BSO and the app stores the result per client. Processing takes a few days, at most 30.

6
Resubmit or correct java human

If SSA returns the file, resubmit the entire corrected file in the same format with RA position 29 set to 1 and the WFID in positions 30 to 35, within 45 days of the notice. One 15-day extension exists. If the file reached COMPLETE and the data was wrong, that is a W-2c through EFW2C (Publication 42-014) or W-2c Online.

The one field that posts wages to the wrong company

SSA posts every employee's earnings to the EIN in the RE record. The rule for positions 8 to 16 is "the EIN under which tax payments were submitted to the IRS under Form 941." A Form 8655 Reporting Agent files and deposits under the client's own EIN, so the client's EIN belongs there and Pyramos appears only once, in the RA record. The Agent Indicator at RE position 7 is not for Reporting Agents. SSA reserves code 1 for Form 2678 agents, code 2 for common paymasters and code 3 for a narrow Section 3504 class (state and local agencies serving home-care recipients). For all three codes the agent's EIN goes in 8 to 16 and the client's EIN in 17 to 25.

!
This is an inference, not a quote. Publication 42-007 never uses the words "Form 8655" or "reporting agent." The treatment below follows from the deposit rule and is almost certainly right, but it decides whose earnings record every wage lands on. Confirm it with an Employer Services Liaison Officer (1-800-772-6270) before the first live file.

Like a courier company's return address on a parcel. The courier is on the label once; the parcel is addressed to the client. Where this breaks: a parcel that goes astray is re-sent. Wages posted to the wrong EIN sit on the wrong earnings record until a W-2c pair moves them, and the client's 941 no longer reconciles.

03 · The EFW2 file for tax year 2026

The format is SSA Publication 42-007, Specifications for Filing Forms W-2 Electronically, tax year 2026 edition, version 1 dated 2026-07-07. Every record is 512 bytes, ASCII, upper case except the two e-mail fields, terminated by CR+LF. Money fields are unsigned digits with an implied decimal point, right-justified and zero-filled: $59.60 is 00000005960. Fields marked Blank are spaces, never zeros. Money fields with nothing to report are zeros, never spaces.

New for tax year 2026

  • Employer Signature PIN at RE 319-328, opt-in for TY2026. If a client opts in, Pyramos must carry that client's PIN or SSA will not process that report. SSA also says "no action is required now for employers." Issued annually. Model it as a nullable per-client, per-year field.
  • Treasury Tipped Occupation Codes in the RW record (Box 14b).
  • Box 12 codes A and B split into separate money fields. Codes J, K, L, P added. Three new codes: TA (Trump Account contributions), TP (cash tips), TT (qualified overtime).
  • Wage base $184,500. Maximum employee SS tax $11,439.00. Household coverage threshold $3,000.
  • Carried from TY2025 and enforced: submitter e-mail and the employer name, delivery address, contact name, phone and e-mail. "Submissions will be returned if any of these fields are left blank."

Limits and hygiene

  • Spec limit 1,000,000 RW and 50,000 RE per submission. The BSO handbook says keep a multi-employer file under 500,000 records total to avoid session timeout. Build to 500,000.
  • Upload cap 350 MB. AccuWage cap 350 MB before zipping. One wage file per .zip.
  • Group every employee of one employer under a single RE. "Unnecessary RE records can cause serious processing errors or delays."
  • A money amount that overflows its field has no legal representation. Fail loudly and call an Employer Services Liaison Officer.
  • W-2 Online (keyed, 50 forms) is decommissioned 2026-09-19. Anything still to key for TY2025 must be in by 2026-09-18. Its replacement handles domestic reports; territories arrive December 2026.

Format groups, so one generator can be sized

  • Copy of the SSA file with RS records and the right state code: DE, DC, MA, WI, VA (VA adds the 513/514 line ending). GA probably, but its RS spec was not read.
  • State-specific record sets or RS/RV content, one profile each: PA (trimmed RA/RE/RS plus its own RV, no RW/RT), MD (no RT/RO/RU, MW508 in RV), OH (single-state file, no RV), NJ (a dozen RS extras).
  • Not EFW2 at all: NY (quarterly NYS-45), and nearly every reconciliation form: PA REV-1667, GA G-1003 and DC FR-900 are CSVs; MD folds MW508 into RV; OH derives IT 3 for free.
  • Layers this page does not cover: quarterly state unemployment wage reports exist in all eleven jurisdictions, often to a different agency (PA UC-2, NJ WR-30, WI DWD). Pennsylvania Act 32 local earned income tax and Ohio municipal withholding (RITA, CCA, self-collecting cities) each need a year-end reconciliation and W-2 copies to the local collector.

Rules that break "one file for all clients"

  • Ohio rejects a file containing non-Ohio RS records. Ohio needs a filtered, single-state file.
  • Virginia runs Complete Business Authentication at upload: it picks accounts from the file at random and asks for the 15-digit account number and total withholding paid. Have those figures for every client in the file.
  • Dormant clients: Maryland cannot take zero-wage bulk filings until calendar 2027; Wisconsin says do not file a WT-7 for an inactive account. Write an explicit rule for clients with no wages.
  • Corrections diverge by state: Massachusetts wants an amended W-2 on paper with the federal W-2c, Delaware takes W-2c/W-3c on paper only, New Jersey wants the W-2c with Form NJ-W-3.
  • Year-round duties ride along: payroll providers acting for 100 or more Virginia taxpayers must remit by ACH Credit; Georgia providers with more than 250 employers must pay by EFT.

05 · Authorization, identity, penalties

Form 8655 does not authorize W-2 filing, and no SSA process references it f8655 · Pub 42-007 §5.2

Form 8655 line 15 lists Forms 940, 941, 943, 944, 945, 1042 and CT-1. Line 18a lets the IRS disclose W-2-series notices to the agent. That is disclosure, not filing authority, but it is what lets Pyramos answer the Combined Annual Wage Reporting notices that fire when a client's W-2 totals do not reconcile to the Forms 941 Pyramos filed. No SSA registration or filing step asks for Form 8655; no SSA page states that in so many words either. What SSA relies on is the BSO User ID in RA positions 12-19, which is a perjury attestation by the person named. For a third party, Pub 42-007 section 5.2 says the attestation "is based on the information available, and assurances provided by the client," and tells submitters to put a client-assurance clause in the service agreement. Add that clause next to the Form 8655 language. Rev. Proc. 2012-32 separately requires a Reporting Agent to remind each client in writing, at contract start and at least quarterly, that the employer remains liable for its deposits and filings.

Identity: BSO takes Login.gov or ID.me, and the credential is personal bsoregug.pdf

Since March 2023 the legacy BSO password is not accepted for sign-in. Both Login.gov and ID.me work. IRS e-Services uses ID.me. Registration is verified against SSA records for the individual (name, SSN, date of birth, address). Activation codes come by mail, one per service, to the address the IRS holds for Pyramos. "BSO User IDs are assigned to and stay with a person." SSA plans an updated authorization system for December 2026 and has run a pilot letting a Responsible Entity Officer manage user access for an entity. Expect the third-party flow to change; re-read the W-2 News page before the season.

SSNVS is the W-2 name check. IRS TIN Matching does not cover W-2 Pub 2108 · ssnvshandbk

IRS Publication 2108 says TIN Matching "cannot enroll employers submitting Forms W-2" and points them to SSA. SSNVS verifies up to 10 name/SSN pairs interactively and up to 250,000 per overnight batch file. Third-party use is limited to firms with a valid wage-reporting contract, only for W-2 purposes, never for pre-hire screening. SSNVS requests carry the client's EIN, not Pyramos's. Run it at hire and again before the season.

Section 6721 covers the copy to SSA. Section 6722 is a second, identical penalty for the employee copy. Filing on paper when e-filing was required is a 6721 trigger. Small-business status is measured on the client. Defenses in the General Instructions: reasonable cause, the de minimis correction rule (on-time file corrected by August 1, waived for the greater of 10 returns or 0.5%), and the dollar-error safe harbor ($100 per amount, $25 for withheld tax). The IRS puts liability on the employer "even if the employer contracts with a third party." Pyramos's exposure is contractual.

The 10-return e-file mandate and the retention rule TD 9972 · Reg. 31.6001-1

Since returns filed in 2024, a filer with 10 or more information returns in a year, aggregated across W-2, 1099, 1095, 5498 and the rest of the list, must e-file them all. Corrections and 94x returns do not count. The count is per filer, meaning the client employer. No IRS page addresses a service bureau's whole book. Practically, put every client in the combined file; below-threshold clients may e-file, and SSA encourages it. Never send paper Copy A for a client whose data is also in the EFW2 file. Form 8508 is the hardship waiver, due 45 days before the W-2 due date. Retain W-2 data and the submission confirmation for four years after the later of the due date or the date the tax was paid.

Electronic employee copies, sick pay, truncation, W-2c Pub 15-A · iw2w3
  • Employee copies may be delivered electronically only with the employee's affirmative consent and the seven disclosures in Publication 15-A. Store consent, channel, timestamp and disclosure version per employee per year. If the original was electronic, the W-2c must be too.
  • Copy A and the EFW2 SSN field carry the full nine digits. Employee copies may be truncated. No logos or slogans on employee copies or envelopes.
  • Third-party sick pay recap reports must not be filed electronically.
  • Form 8809 extension for W-2 is non-automatic, one 30-day period, paper only, granted for extraordinary circumstances, and itself due January 31. Form 15397 extends the employee-copy deadline. Neither is a planning tool.
  • A client that closes has an earlier deadline: W-2s are due by the last day of the month after its final Form 941. With client churn this fires several times a year.
  • Required RE fields the pipeline must set for every client: Kind of Employer (174), Employment Code (219, and code H interacts with the $3,000 household rule), Tax Jurisdiction Code (220, blank for domestic), Third-Party Sick Pay Indicator (221). On RA: Software Code 98 and Preparer Code S.
  • SSA names suspended third-party submitters publicly under POMS RM 01101.004 (dated 2026-01-27).

06 · What to build in this repo

Nothing here touches the MeF session code. An EFW2 generator is a pure function from domain objects to bytes plus a validator, with no network calls and no reflection. It is the most testable thing that could be added to this repository, and no maintained Java library exists for it (Maven Central's only hit for EFW2 is an unrelated framework). The format knowledge is the asset; own it.

Domain model, then derived records

Money is long cents everywhere. Totals are computed, never accepted as input, which removes the "RT does not match RW" rejection class.

Keep the exact file and its hash. A resubmission must be the same format with the same WFID, and reconstructing January's file from a payroll database that has moved on is how a two-hour fix becomes a two-day one.

Two deliverables the file alone does not cover

  • Employee copies. Pub 42-007 says an EFW2 file cannot produce a Form W-2. Copies B, C and 2 are due to employees on the same 2027-02-01, and IRC 6722 is a second penalty of identical size for them. The pipeline needs a W-2 rendering step (PDF from the same domain model) plus the consent record for electronic delivery.
  • Corrections. A first season guarantees some. Federal corrections are EFW2C (nine RC* record types) or W-2c Online for low volume. State corrections diverge: MA paper, DE paper only, NJ with NJ-W-3. Model a correction as a new run keyed to the original WFID rather than a patch.
  • Reconciliation to the 941s. Each client's W-2 totals must match the four Forms 941 this repo already files. Add a pre-generation check that sums RW wages and withholding per client against the 941 quarters. Mismatches surface later as IRS/SSA CAWR notices.

Security of the wage file

  • One file will hold full SSNs, names, addresses and wages for every employee of every client. Treat it as the most sensitive artifact in the system.
  • Encrypt at rest with a key outside the application database. Restrict read access to the two BSO-registered staff. Log every read.
  • Retention is four years, then destruction. Record destruction as an event.
  • Write the information security plan a third-party payroll and tax filer is expected to hold, and put breach-notification steps in it. This gap is larger than any formatting risk on this page.
  • Never log a record. Existing repo rules on sensitive payloads apply to the RW record verbatim.

If 1099s are on the roadmap, apply to IRIS now

IRIS A2A is REST with JWT bearer tokens, not SOAP. The ETIN, ASID and EFIN do not carry over. The IdenTrust device certificate does: Pub 5718 says "you can use the same public certificate as used for other IRS programs such as MeF." That ties IRIS token issuance to the same 2027-08-21 expiry as MeF login. IRIS TCC processing runs about 45 business days and FIRE stops accepting returns on 2026-11-19. Combined Federal/State Filing for 1099s covers nine of Pyramos's jurisdictions but not New York or Virginia.

07 · Gotchas

Do not rediscover these

  1. The RS record in the SSA file is inert. SSA and IRS do not read it, and nothing reaches any state. State filing is a second submission.
  2. Every BSO upload is live. No test flag, no test environment. The first real AccuWage pass is the test.
  3. Form 2678 agents use Agent Indicator 1, not 3, with the agent EIN in 8-16 and the client EIN in 17-25. A Form 8655 Reporting Agent uses no indicator and puts the client EIN in 8-16. SSA has never written that sentence down; confirm it by phone before the first live file.
  4. RA EIN must equal the BSO registration EIN, or the file cannot be resubmitted through BSO at all.
  5. Pub 42-007 section 7.3 still says files "after February 2, 2026" are late. That is stale TY2025 text. The TY2026 date is 2027-02-01.
  6. Pub 42-007 says IRIS is the preferred way to file Form 8809. Form 8809 itself says W-2 extension requests must be on paper. The form wins.
  7. Four states reject an unmodified SSA file: PA (own RA/RE/RS/RV, no RW/RT), OH (Ohio-only RS, no RV, RE 319-512 blank), MD (no RT/RO/RU, RV carries MW508), NJ (a dozen extra RS fields). VA and DC have their own ordering and line-ending rules.
  8. The EFW2 file does not produce the employee copies, and the employee-copy penalty is the same size as the filing penalty. Half the exposure needs its own artifact.
  9. The BSO handbook and the returnfilers page are still TY2025 editions. Trust the TY2026 Pub 42-007 for dates. Re-read everything in late November, when SSA's December authorization changes and the signature PIN land.
  10. Do not script the BSO browser. It defeats a federal MFA control, SSA prohibits screen scraping, and suspended submitters are named publicly.
  11. January 31, 2027 is a Sunday. Everything rolls to Monday February 1 except New Jersey (February 16 by rule, February 17 in its 08/2026 spec).

09 · Open items, how this was researched, sources

Open items

Reporting Agent treatment in the RE record
Client EIN in 8-16 with position 7 blank follows from SSA's deposit rule but is not stated by SSA anywhere. Highest-consequence open item. One phone call closes it.
Does SSA ever ask for Form 8655?
No SSA process references it and no SSA page says so. Treated here as "not referenced," not as a stated rule.
Machine channels in PA, DE, GA, OH, DC
None is published. That is absence of evidence, not a published denial.
New Jersey deadline
NJ-WT says February 15 rolled to the next business day, which is Tuesday February 16, 2027. The 08/2026 NJ-EFW2 spec says February 17 without explanation. File by the 16th unless the Division of Revenue confirms the 17th in writing.
Georgia RS deviations
dor.georgia.gov blocks non-browser clients and its file-formats page has no archive copy. Georgia accepts the federal file, but any RS repurposing was not read.
TY2026 state layouts
Ohio, Maryland, Wisconsin and DC have not posted TY2026 specs. Their rows show TY2025 rules with derived dates. Massachusetts' withholding guide still mentions a March date for some filers; its W-2 page does not restate January 31.
December 2026 SSA changes
Whether the updated BSO authorization system adds per-client steps for third-party submitters is unknown. Today, clients need no BSO account.
New York FSET
Whether Pyramos can transmit NYS-45 data via FSET XML without a separate software-developer approval cycle was not verified.
State FIPS codes
DE 10, DC 11 and GA 13 are assumed from the standard table. MA 25, MD 24, NJ 34, OH 39, PA 42, VA 51 and WI 55 are restated in the states' own specs.
