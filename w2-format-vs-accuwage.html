Is our W-2 file the AccuWage file?

Yes. We generate one W-2 format, the SSA wage file. The files we upload to AccuWage are the same bytes that same code would send to SSA for real. There is no HTML W-2 anywhere in the repo.

What the file is, in plain words

It is a plain text file. Every line is exactly 512 characters, padded with spaces, ending in a Windows line break. There are no commas, no tags, no field names. SSA knows what each value is purely by where it sits on the line. Position 3 to 11 on a submitter line is the EIN, and so on. SSA calls this format EFW2 and documents it in Publication 42-007.

A file is a short stack of line types:

LineWho or whatHow many
RAWho is sending the file. For us that is Pyramos, with the BSO user ID and a contact.1 per file
REOne client employer: EIN, name, tax year.1 per employer
RWOne employee's W-2: SSN, name, wages, taxes withheld, Box 12 amounts.1 per W-2
RTTotals for that employer, which must add up to its RW lines.1 per employer
RFEnd of file, with the count of all RW lines.1 per file

One Reporting Agent file can carry several employers: RA, then RE/RW/RT repeated per client, then RF. Test file 02 does exactly that with three clients.

Why the AccuWage copy and the real copy are the same

  • One writer. The class Efw2Writer builds every line. The test files and the real build endpoint (POST /mef/wage-files) both call it. Nothing is reformatted for AccuWage.
  • AccuWage checks the upload format. AccuWage Online is SSA's free pre-check for the exact file BSO's "Upload Formatted Wage File" takes. If AccuWage says no errors, BSO accepts the same bytes.
  • Only the data differs. Test files use made-up employers and employees. A real run uses a client's payroll and Pyramos's real EIN and BSO user ID in the RA line.

Three things to keep in mind

  • It is not on main yet. The generator lives on the local branch feature/w2-accuwage-files, unpushed. Main only has the generated files under reports/accuwage-ty2025 and reports/accuwage-ty2026.
  • Test with the 2025 set first. AccuWage may reject a tax year 2026 file before January 2027, so the 2025 files are the ones to upload now.
  • Federal only, no extras. We write RA/RE/RW/RT/RF. We do not write RO/RU lines (needed for tip and overtime Box 12 codes) or RS state lines. State W-2 filings are separate files with their own rules per state.
